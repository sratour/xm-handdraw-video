# 画风配方规范

一个画风 = 一个 `styles/<id>.md` 文件。文件名（去掉 `.md`）就是画风 id。

## 结构：五段式

```markdown
## <编号> <id> <画风名>

> 别名：<英文短名1>、<英文短名2>
> 唯一主视觉真源：assets/<id>/anchor.png
> 正式合同：<基础生成后要几轮修正，每轮只改什么>
> 命门：①<不可动摇的特征1>；②<...2>；③<...3>
> 【文字】填法：<要标题怎么写，不要怎么写>

```
<正文：一整段可直接投喂的提示词，必须含 【主体】 占位符>
```
```

解析规则（`scripts/recipe.py`）：

- `## ` 标题行 → id 与名称。`## 1 retro-mystery-manga 九十年代周刊少年推理漫画`
  会解析出 id = `retro-mystery-manga`，名称 = `九十年代周刊少年推理漫画`
- `> 字段名：值` → 元数据。续行（下一行也是 `>` 开头）会自动并入上一个字段
- 围栏内的内容 → 正文。**一个文件只放一个围栏块**，否则会全部并入正文
- 正文里的 `【主体】` 会被替换成调用时传的 `--subject`

## 各字段的作用

| 字段 | 必填 | 作用 | 不写会怎样 |
|---|---|---|---|
| 别名 | 否 | 调用时可以用短名命中 | 每次都要贴完整 id |
| 唯一主视觉真源 | 强烈建议 | 锚点图路径。存在时随每次生图传入 | 风格会在每张图之间飘 |
| 正式合同 | 否 | 声明多阶段修正，以及每轮只改什么 | 一次生成不满意就没有收敛手段 |
| 命门 | 强烈建议 | 编号列出不可动摇的特征，用于出图后自检 | 改到第三版就丢了最初的味道 |
| 【文字】填法 | 否 | 画面内文字的写法 | 画面里可能出现乱码或多余文字 |

## 正文怎么写

按这八段组织，顺序可以调，但不要漏：

1. **参考图指令**——声明锚点图的优先级，以及「只继承风格，不复制人物、服装、站位、情节」
2. **媒介与气质**——这是什么，不是什么（用「不是 A，不是 B」排除常见误判）
3. **画面内容**——`【主体】`
4. **构图**——主体位置、留白、背景复杂度上限
5. **人物比例**——头身比、肩宽、四肢、允许的不对称
6. **脸部身份锁**——眼睛 / 眉 / 鼻 / 嘴 / 肤色，逐项写死，并列出禁止项
7. **线稿与上色**——线条粗细与变化、抖动程度、色板、明暗层数、阴影方式
8. **NO 约束**——8~15 条，把常见走样方向逐条堵死

## 三条经验

**不要写艺术家姓名。** 生图模型对在世艺术家的名字有过滤，写了容易被拒；
就算不拒，「名字」对模型也是弱信号，不如直接描述线条和五官。

**「命门」要写具体到能肉眼核对。** 「眼睛大而圆润」没法验收；
「上眼睑一条加粗黑线，瞳孔内只留一个明确的白色高光点」可以。

**用 NO 约束收尾。** 免费通用模型有很强的「往漂亮/往现代/往精细」跑的倾向，
不堵住就会慢慢偏离你要的复古感。这是实测中最有效的一条。

## 多阶段修正

实测经验：**一次强修正会擅自改掉配色和人物形态**，递进式两轮才稳。

| 轮次 | 只改什么 | 不许碰什么 |
|---|---|---|
| 第 1 轮 | 线稿匀度、脸部五官、人物比例 | 上色、背景、构图 |
| 第 2 轮 | 上色、网点密度、留白 | 线稿、五官、构图 |

写进配方时用一句话声明：

```
正式合同为 <id>-v3：基础生成后必须依次做两轮只改 <维度> 的编辑。
第一轮只处理 <X>，第二轮只处理 <Y>；前两阶段都不是 final。
```

## 锚点图

路径写 `assets/<id>/anchor.png`。文件不存在时脚本会自动降级为「纯提示词模式」，
不会报错，但风格稳定性会明显下降。

生成锚点的推荐做法：用配方正文跑 30~50 张，逐张看，
挑线条、五官、比例、上色四项都最对味的一张存下来。
之后**每次生图都带着它**。锚点一旦定下就不要换。

## 验收清单

出图后逐条核对，全部通过才算这张图合格：

- [ ] 线条粗细有变化，不是均匀描边
- [ ] 五官符合「脸部身份锁」的每一条
- [ ] 头身比、肩宽、脸型在预设范围内
- [ ] 上色是平涂，没有渐变和发光
- [ ] 阴影只出现在该出现的深阴影处
- [ ] 背景复杂度在预算内
- [ ] 画面内没有多余文字或 logo
- [ ] 和锚点图放一起看，像同一个画师画的
- [ ] **只继承了风格，没有复制锚点图里的人物、服装、站位、情节**
