# 道具库

写 `subject` 时对照这张表挑 2-3 件，别让画面只剩「一个人 + 一面白墙」。

**用法**：先定主题落在哪一类 → 从「可放道具」里挑 2-3 件 → 给每件写清位置。
道具必须**跟这一场的旁白相关**，不是为了填而填。

位置词库（直接抄）：`头顶` `脚边` `身旁` `身后` `左手边` `右手边` `正前方`
`墙上挂着` `桌上放着` `地上摆着` `窗外是` `背景里` `角落里` `架子上` `柜台后`

## 抽象概念怎么落地

讲「成本」「流程」「对比」这类没有实体的东西，别让模型画空气。给它**可数的实物**：

| 想表达 | 画成什么 |
|---|---|
| 成本高 | 一叠账单、一只标着数字的价签、一堆硬币 |
| 流程分几步 | 桌上并排放三个贴着标签的盒子／三张卡片 |
| 两边对比 | 桌子左边一堆物件、右边一堆物件，中间留空 |
| 数据下降 | 墙上挂一块折线向下的图表板、一支指示杆 |
| 时间很长 | 墙上一只挂钟、桌上翻开的日历、旁边一只沙漏 |

## 通用填充件（哪一类都能塞）

绿植、挂画、窗帘、地毯、纸箱、书架、灯具、水杯、抱枕、门、窗、台阶

> 注意：这五件最容易「塞了但没用」。只在主道具凑不够 2 件时用它兜底，
> 优先选跟主题有关的。

## 容易被画错的东西

这几样光写名词不够，模型的默认理解跟你要的不一样，必须补定语。

| 你写的 | 实际会画成 | 要补的定语 |
|---|---|---|
| 手机 | 带数字键盘的功能机，甚至**座机**（有听筒、螺旋线） | 「黑色全面屏智能手机，正面几乎全是屏幕、没有任何实体按键、没有听筒、没有数字键盘」 |
| 路缘石刷黄漆 | 路面上的一大块黄色色块，看不出是台阶 | 「有厚度的路缘石台阶，台阶的侧面整条刷成黄色，能看出它是高出路面的、不是路面上画的一条线」 |
| 气缸 / 燃烧室 | **蜡烛**（圆筒 + 顶部火焰的组合特征太强） | 换视觉：透明亚克力外壳的剖面模型 + 带旋转箭头的飞轮，别画火焰 |
| 一辆车 | 三轮汽车画成四轮马车 | 写死轮子数量 + 「不是马车」 |

手机这一条尤其容易漏：一期视频里手机出现五六次，只要有一处没写全，
观众就会看到「同一个人一会儿用智能手机、一会儿用老人机」。

## 反面清单

- **纯色背景**：只写「背景是浅米色墙面」→ 出来就是一面白墙
- **只罗列不写位置**：写「沙发、茶几、电视」不分位置，模型会挤成一堆
- **塞无关物件**：讲电费放哑铃、讲方向盘放花瓶 → 分散注意力，观众会出戏
- **道具比人还大**：道具是为了衬托主体，别让它抢画面中心
